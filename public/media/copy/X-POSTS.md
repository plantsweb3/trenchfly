## Short answers

### Is this trading real funds?

The public launch is a paper experiment. It reads market data and records simulated outcomes. The session labels its mode and timestamps.

### Is this a living fly?

No. It is a computational model based on a mapped fruit-fly connectome. The character is a visual representation of the experiment.

### Does it choose which token to inspect?

Software selects from supported pools and presents a chart. The neural response feeds a BUY, SELL or HOLD proposal for that input.

### Is the network animation real?

The motor numbers and spike trace come from the simulation. The mesh layout and decorative pulses are schematic, not a map of measured activity in individual neurons.

### Has it learned to make money?

Profitable learning has not been demonstrated. We publish the inputs, responses and outcomes so the work can be inspected.

### Is RobinFly affiliated with Robinhood?

No. RobinFly is an independent experiment using Robinhood Chain market data.

### Why does the GitHub URL say trenchfly?

RobinFly was previously named TrenchFly. The existing repository path remains in place to preserve its history and working integrations. The official site is robinfly.net.
